[BisonClient source code](https://github.com/bison-markets/sdk-ts/blob/master/src/client.ts).

## Overview

The Bison API provides real-time market & event data streams via WebSockets. This allows you to receive updates as they happen, rather than polling for updates at fixed intervals.
